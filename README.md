COWBOOK is a farm data management site to store, search, apply filters and update stored data of farm animals .
User can create a profile and edit its profile.
User can update or stored more attributes  to a already existing animal by simply searching the animal from it's tag number.
User can store the details new animals by simply clicking the add button.
to run this project on your PC follow the following steps-
cd to javascript.code.
add your API key in CBsever.js in POST /ask route update PostgreSQL database and password and create tabels farm_data with columns (id, dob, lactations, inseminated, doi) .
install node modules by running (npm i) command in terminal.
run command (node CBserver) in terminal.
go to localhost:3000 on the web browser.
the site should be visible.
